## 📌 About The Project

**Aqua Dive Egypt** is a modern responsive website for a professional diving center.

The website provides information about:

- Diving courses
- Famous diving locations
- Gallery of underwater experiences
- Contact information
- About the diving center

The design focuses on a clean underwater theme with a smooth user experience across all devices.

---

## ✨ Features

- 🌊 Responsive design for all screen sizes
- 🎨 Modern UI using Tailwind CSS and DaisyUI
- 🌙 Dynamic theme switching
- 🏠 Home page with diving introduction
- 🤿 Diving courses showcase
- 🐠 Famous dive sites:
  - Blue Hole
  - Ras Mohammed
- 📸 Underwater gallery
- 🗺️ Google Maps integration
- 📱 Mobile-friendly navigation
- 🎯 Clean card-based layouts


